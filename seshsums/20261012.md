## Moving the site

### Plan (as agreed at the start of the session)
- **Source:** the Google Site at `sites.google.com/view/elizagen-org/`. Before the move, elizagen.org redirected there.
- **Target:** GitHub Pages on `jeffshrager/elizagen.org`, built from `master` at `/`. Pages was already enabled.
- **Format:** plain static HTML, one standalone file per page with the nav bar copied in. No Jekyll templating, although the legacy Jekyll build still runs and passes HTML through unchanged.
- **Google Drive links:** left pointing at Drive; nothing was downloaded.
- **Images:** downloaded into `site/images/`. Google's image URLs are signed per session, so the pages had to be fetched with a cookie jar and converted immediately.
- **Links:**
  - Links between pages of the old site point at the local pages.
  - Google redirect wrappers (`google.com/url?q=`) were unwrapped.
  - Links to `github.com/jeffshrager/elizagen.org/...` point at local files when the file exists in the repo.
- **Cutover:** commit without a `CNAME` first and preview at `shrager.org/elizagen.org/`. Then set the custom domain and change the DNS.
- **Checks:** a link checker for local links and images, a scan for leftover Google URLs, and a text comparison against the original pages.

### Differences from the plan
- **About** points at `index.html`, because the Google Site's About page was identical to its home page.
- **The Home-page image carousel** became a grid of 11 images, each with a "Caption to come." placeholder for Jeff to fill in.
- **Spacing:** Google Sites stored code and transcript listings as one paragraph per line. Short, line-like paragraphs are therefore marked `class="tight"`, and stray `<br>`s between paragraphs were removed.
- **The conversion scripts are not in the repo.** They lived in a temporary session folder, so the HTML files are now the master copies.

### DNS cutover (done by Jeff at GoDaddy)
- **Apex A records:** 185.199.108–111.153.
- **The real culprit:** a GoDaddy "Parked" A record that kept returning 3.33.251.168 and 15.197.225.128 (GoDaddy's parking/forwarding servers). It had to be deleted.
- **`www`:** GitHub's health check wants the `www` CNAME to point at `shrager.org` rather than `jeffshrager.github.io`, because the user site has its own custom domain.
- **HTTPS:** the certificate was approved.
